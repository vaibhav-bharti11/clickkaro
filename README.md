# Click Karo Date Karo (Social & Lifestyle Support Platform)

> India's #1 Safe, Verified Social & Lifestyle Support Network (A unit of **SET INDIA BUSINESS PVT LTD**).

## Overview
Click Karo Date Karo provides background-checked, KYC-verified companions for cinema, dining, elder care, shopping, clubbing, and city exploration across 19,000+ Indian postal pin codes.

## Features
- **100% Aadhaar & KYC Verification**: Screened companions and seekers with biometric/government ID validation.
- **Strict Consent-First Protocol**: Zero-judgment, professional code of conduct with 24/7 in-app emergency SOS safety tracking.
- **Seeker Hub**: Hyperlocal location selector (city & 6-digit pin code) with interactive swipeable companion cards.
- **Companion Partner Dashboard**: Live earnings simulator (80% net take-home weekly payouts), incoming seeker booking requests (Accept / Decline), and session management.
- **LandingHero.AI Inspired Design**: Translucent glassmorphism panels, kinetic typography, voice-wave presence indicators, and ethereal baby pink motion layer.
- **Unified Dual-Role System**: Any user can seamlessly switch between Seeker and Companion modes with one click.

## Tech Stack
- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Vanilla CSS Glassmorphism
- **Icons & Motion**: Lucide React, Canvas Confetti
